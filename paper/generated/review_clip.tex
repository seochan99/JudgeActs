The CLIP baseline embeds the raw prompt (no template; all prompts fit the 77-token limit) and each image with the default CLIP preprocessing (resize and center crop to 224 pixels), and returns the image with the highest cosine similarity; ties follow canonical order. Our main baseline uses ViT-L/14. A smaller ViT-B/32 backbone gives nearly the same gain (0.063 [0.042, 0.085]; difference $-$0.006 [$-$0.028, 0.018]), but no stereotype increase (0.003 [$-$0.016, 0.023]), so the stereotype effect of a similarity scorer depends on the backbone (Appendix Table~\ref{tab:extras-clip}).

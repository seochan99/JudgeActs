# CulturalFrames: Assessing Cultural Expectation Alignment in Text-to-Image Models and Evaluation Metrics

The increasing ubiquity of text-to-image (T2I) models as tools for visual content generation raises concerns about their ability to accurately represent diverse cultural contexts. In this work, we present the first study to systematically quantify the alignment of T2I models and evaluation metrics with respect to both **explicit** (stated) and **implicit** (unstated, implied) cultural expectations.

To this end, we introduce **CulturalFrames**, a novel benchmark designed for rigorous human evaluation of cultural representation in visual generations. Spanning **10 countries** and **5 socio-cultural domains**, CulturalFrames comprises:

- **983 prompts**
- **3,637 images** generated by **4 state-of-the-art T2I models**
- **Over 10,000 detailed human annotations**

## Dataset Structure

This dataset is available as a single split named `train`, consisting of **3,637 rows**. Each row includes the following fields:

| Column Name | Type     | Description |
|-------------|----------|-------------|
| `id`        | `string` | Unique identifier for each data entry. |
| `prompt`    | `string` | The textual prompt used as input to the T2I models. |
| `image`     | `image`  | The generated image corresponding to the prompt. |
| `country`   | `string` | The country associated with the cultural context (10 unique values). |
| `model`     | `string` | Name of the T2I model used for generation (4 distinct models). |

---

## Annotations

The annoatations are present in `culturalframes_human_annotations.json` file. The dataset is a JSON list of objects. Each object represents a single image-prompt instance and its associated human annotations.

### Top-Level Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | String | A unique identifier for the instance. You can use this to link it to the HuggingFace dataset. |
| `prompt` | String | The text prompt used to generate the image. |
| `country` | String | The target country for the cultural context. |
| `category` | String | The cultural category of the prompt (e.g., `family`, `religion`, `etiquette`, `greetings`, `dates-of-significance`). |
| `model_name` | String | The name of the AI model that generated the image (e.g., `gpt-image`, `flux`, `SD35`, `imagegen3`). |
| `human_annotations` | List | A list of annotation objects provided by human evaluators. |

---

## Human Annotations Fields

Each entry in the `human_annotations` list contains the following sub-objects:

### 1. `stereotype`
Evaluates the presence of cultural stereotypes in the image.
- **`is_stereotypical`** (Boolean): `true` if the annotator believes the image relies on stereotypes; `false` otherwise.
- **`comments`** (String): Qualitative details explaining the reasoning behind the stereotype assessment.

### 2. `demographic_data`
Provides context about the annotator's background.
- **`age`** (String): The age of the annotator.
- **`sex`** (String): The sex/gender of the annotator.
- **`ethnicity`** (String): The ethnicity of the annotator.
- **`country_of_birth`** (String): The country where the annotator was born.
- **`country_of_residence`** (String): The country where the annotator currently lives.
- **`nationality`** (String): The nationality of the annotator.
- **`language`** (String): The primary language of the annotator.
- **`student_status`** (String): Current student status (e.g., "Yes", "No").
- **`employment_status`** (String): Current employment status.

### 3. `prompt_alignment`
Measures how well the image represents the text prompt.
- **`score`** (Float): Can be 0.0, 0.5 or 1.0 indicating alignment quality.
- **`missing_explicit`** (Boolean): `true` if objects or concepts explicitly named in the prompt are missing.
- **`missing_implicit`** (Boolean): `true` if cultural nuances implied by the prompt are missing.
- **`selected_words`** (String): Specific words or phrases from the prompt that were poorly represented.
- **`comments`** (String): Detailed feedback on the alignment.

### 4. `image_quality`
Assesses the technical and visual integrity of the image.
- **`score`** (Float): Can be 0.0, 0.5 or 1.0 indicating image quality.
- **`artifacts`** (Boolean): `true` if there are noticeable AI-generated artifacts (e.g., distorted limbs).
- **`unnatural`** (Boolean): `true` if the image looks physically or culturally "uncanny".

### 5. Summary Fields
- **`overall_score`** (Float): The annotator's final rating for the image (typically on a scale of 1-5).
- **`feedback`** (String): General comments or concluding thoughts from the annotator. This can be sometimes very useful.

## Usage Example

Here’s how you can load the dataset using the Hugging Face `datasets` library:

```python
from datasets import load_dataset

dataset = load_dataset("mair-lab/CulturalFrames", split="train")
print(dataset.column_names)  # ['id', 'prompt', 'image', 'country', 'model']

first = dataset[0]
print("Prompt:", first["prompt"])
print("Country:", first["country"])
print("Model:", first["model"])

# To display the image (if in a notebook context):
from PIL import Image
import IPython.display as display
display.display(first["image"])
```
